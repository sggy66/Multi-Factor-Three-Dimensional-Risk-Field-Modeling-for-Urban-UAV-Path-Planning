# Multi-Factor-Three-Dimensional-Risk-Field-Modeling-for-Urban-UAV-Path-Planning
Code, processed data and results for Multi-Factor Three-Dimensional Risk Field Modeling for Urban UAV Path Planning.

Download and use

1. Download the [reproducibility package](./Reproducibility_package_title_checked_20261013.zip).
2. Extract the archive and open the `UAV_Planning_Reproducibility` folder.
3. Follow the enclosed `README.md` for installation, experiment execution and verification.

## Package contents

- Python code for field construction, path planning, trajectory reconstruction and evaluation.
- Processed study-area inputs and fixed experiment configurations.
- Reference results, trajectory files and summary tables.
- Methods, pseudocode, data-source descriptions and measured computational performance.

The six factor fields represent dimensionless planning costs and exposure proxies, rather than calibrated accident or casualty probabilities. Original data sources and preprocessing are documented in `docs/DATA.md` inside the archive.
